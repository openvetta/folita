# 0004. 沙盒内读取被复制的图片文件

- 状态：已采纳
- 日期：2026-10-21

## 背景

复制文件时，剪贴板里只有文件地址（`public.file-url`），没有内容。希望在历史列表与详情里把被复制的图片文件显示成缩略图和大图，就必须在用户之后任意时刻读取该文件。ADR 0001 让应用开启 App Sandbox，沙盒默认读不了用户目录里的任意文件，仅有 `files.user-selected.read-only`（需要用户主动选择）。

## 决策

- 在 entitlements 增加 `com.apple.security.temporary-exception.files.absolute-path.read-only`，路径为 `/`，只读、不可写。
- 只对「恰好一个、扩展名属于图片类型」的文件读取，用 ImageIO 在后台线程解码缩略图；读取失败（文件被删除、无权限）时回退为文件图标。
- 不保存文件内容的副本：历史里仍只存文件地址，缩略图按需生成。

## 备选方案

- **复制时抓取缩略图并存入历史**：不放宽沙盒，但依赖剪贴板为后台轮询授予的临时访问权限，未经验证，且会增大存储。未采用。
- **只显示文件图标**：无需权限，但图片文件看不到内容。未采用。

## 后果

- 沙盒被放宽为「可读取全盘」。该例外在 Mac App Store 审核中通常不被接受；若未来上架，需要改为复制时抓取缩略图的方案或让用户授权目录，届时重新评估。
- 应用不会写入这些文件，也不读取图片以外的文件内容。
